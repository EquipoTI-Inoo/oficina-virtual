# Integraciones

- `inoowork/`: requiere el parche de seguridad desplegado (INO-00) y la API key de integración por header `x-api-key`.
  Sincronización por consulta cada 5 min (decisión 4 de la arquitectura).
- `google-drive/`: estructura de carpetas del PRD; prefijos `BORRADOR_` / `APROBADO_`.
- `wordpress/`: los blogs se crean como borrador, nunca publicados directamente.
- `paid-media/`: Fase 2/3.
